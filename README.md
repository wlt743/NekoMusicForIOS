# NekoMusic for iOS

第三方音乐播放器客户端（SwiftUI）。**应用本身不内置曲库，也不默认连接任何服务器。**

## 首次启动

1. 阅读并同意《技术架构与使用边界声明》
2. 选择接口服务器：
   - **使用 NekoMusic 资源**：填入社区常用地址（由第三方提供与维护）
   - **自己配置**：填写你自己的接口服务器地址

未经同意、未选择服务器之前，应用不会发起任何请求。

## 声明要点

- 本应用是纯本地客户端，开发者不运营音乐服务，不存储、不上传、不中转、不筛选、不编辑任何音乐内容
- 播放与下载在你的设备与你指定的服务器之间直接进行
- 你应自行确保所接入服务器及内容的合法授权

完整声明见应用首次启动页。

## 功能

- 首页推荐 / 最新 / 排行，搜索，歌单与收藏
- 逐行歌词、锁屏与待机显示、Live Activity
- **声音震动**（CoreHaptics，iPhone 8 / iOS 13+）：跟随音频响度与音色产生触感
  - 分频段频谱通量与音色特征驱动强度与锐度
  - 多档预设（柔和 / 标准 / 强烈 / 超强）与四个自定义槽
- 客户端身份 v1（实例签名）与请求防重放（一次性 nonce + PoW）

## 构建

```bash
xcodebuild -project NekoMusic.xcodeproj -scheme NekoMusic -configuration Release build
```

需要自行配置签名团队（`DEVELOPMENT_TEAM`）。
